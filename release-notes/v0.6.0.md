# Цены на всём Kufar

## Коротко

Расширение теперь работает на главном домене kufar.by, а не только на поддоменах auto, re и travel. В попапе появился общий переключатель «Везде», который включает или выключает замену цен сразу на всех разделах Kufar. Для магазинов расширений добавлены изображения для витрины.

---

## Что изменилось

### Для пользователей Kufar

* **Главный домен kufar.by:** расширение теперь умеет заменять цены на основном сайте kufar.by. Раньше корректная работа была только на поддоменах — auto, re, travel. Теперь не нужно специально переходить на поддомен, чтобы видеть цены в выбранной валюте.
* **Общий переключатель «Везде»:** в попапе появился переключатель, который одним движением включает или выключает замену цен на всех разделах Kufar сразу. Удобно, если хотите временно отключить расширение на всём сайте.

### Работа в браузере

* **Изображения для витрины:** добавили промо-изображения для страниц расширения в магазинах Firefox и Chrome. Это поможет новым пользователям быстрее познакомиться с расширением.
* **Сборка стала чище:** при сборке расширения в пакет больше не попадают лишние файлы из папки с иконками.

---

## Исправили

# Prices Everywhere on Kufar

## Summary

The extension now works on the main kufar.by domain, not just on auto, re, and travel subdomains. The popup has a new "All" toggle that enables or disables price conversion across all Kufar sections at once. Promo tile images have been added for browser extension stores.

---

## What changed

### For Kufar users

* **Main kufar.by domain:** the extension can now convert prices on the main kufar.by website. Previously, it only worked reliably on subdomains (auto, re, travel). You no longer need to visit a subdomain to see prices in your chosen currency.
* **Global "All" toggle:** the popup now has a master switch that enables or disables price conversion across all Kufar sections at once. Handy when you want to temporarily turn off the extension on the entire site.

### Browser experience

* **Store listing images:** added promo tile images for extension pages in the Firefox and Chrome stores. This should help new users discover the extension more quickly.
* **Cleaner build output:** the extension package no longer includes unnecessary files from the icons folder.

---

## Fixed

* Fixed the user count badge in the README — the Mozilla badge now shows the correct install count.
* Added a working Chrome Web Store link in the README.

---

## What this means for users

The extension now works across the entire Kufar site, including the main domain. You can enable price conversion on all pages at once with a single toggle in the popup.
