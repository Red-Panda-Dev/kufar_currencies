# Обновленные цвета попапа

## Коротко

В этой версии обновлена цветовая палитра всплывающего окна расширения. Попап теперь использует палитру Kanagawa Wave — спокойные, приглушенные тона, которые приятнее воспринимаются глазом. Цвета текста, кнопок и фона стали более согласованными и контрастными.

---

## Что изменилось

### Работа в браузере

* **Новая палитра попапа:** всплывающее окно расширения теперь оформлено в цветовой гамме Kanagawa Wave. Текст стал теплее, акценты — мягче, а состояния успеха и ошибки различаются четче за счет новых семантических цветов (зеленый для подтверждений, красный для ошибок).

---

## Что это значит для пользователя

Обновление касается только внешнего вида всплывающего окна. Конвертация цен, курсы валют и работа на страницах Kufar.by не изменились. Попап должен быть приятнее и удобнее для ежедневного использования.

---

## Полный список изменений

* Обновлена цветовая схема всплывающего окна расширения (палитра Kanagawa Wave)
* Улучшена согласованность цветов в попапе — убраны жестко заданные цвета в пользу переменных
* Добавлены отдельные цвета для состояний успеха и ошибки

# Updated Popup Colors

## Summary

This version updates the color palette of the extension popup. The popup now uses the Kanagawa Wave palette — calm, muted tones that are easier on the eyes. Text, button, and background colors are more consistent and have better contrast.

---

## What changed

### Browser experience

* **New popup palette:** the extension popup is now styled with the Kanagawa Wave color scheme. Text is warmer, accents are softer, and success/error states are more clearly distinguished through new semantic colors (green for confirmations, red for errors).

---

## What this means for users

This update only affects the appearance of the extension popup. Price conversion, exchange rates, and behavior on Kufar.by pages are unchanged. The popup should feel more pleasant and comfortable for everyday use.

---

## Full changelog

* Updated the extension popup color scheme (Kanagawa Wave palette)
* Improved color consistency in the popup — replaced hardcoded colors with CSS variables
* Added dedicated colors for success and error states
