# Удобнее курсы валют

## Коротко

В этой версии стало проще настроить курсы под себя прямо в попапе расширения. Если автоматический курс не подходит, его можно изменить вручную, а расширение будет использовать этот курс для отображения и конвертера. Версия также подготовлена как релиз 1.0.0 для Firefox и Chrome-based браузеров.

---

## Что изменилось

### Для пользователей Kufar.by

* **Свои курсы в попапе:** теперь курс USD, EUR или RUB можно изменить вручную. Это удобно, если нужен курс банка, обменника или другой ориентир вместо автоматического курса.
* **Заметные ручные значения:** измененные вручную курсы выделяются в списке. Так проще понять, где используется свой курс, а где автоматический.
* **Более компактный попап:** окно расширения стало фиксированной ширины и использует темное оформление. Элементы с курсами и конвертером должны выглядеть аккуратнее в небольшом окне браузера.

### Курсы и валюты

* **Курс сохраняется:** ручной курс сохраняется в браузере и продолжает применяться после обновления курсов. Это снижает риск, что выбранное вручную значение пропадет после новой загрузки данных.
* **Можно вернуть автоматический курс:** для измененного курса можно убрать ручное значение и снова использовать курс, полученный автоматически.
* **Конвертер учитывает ручной курс:** если для валюты задан свой курс, конвертер в попапе считает BYN по нему. Результат теперь показывается в более понятном виде: сумма в BYN с двумя знаками после запятой.
* **Курсы стали короче:** значения курсов в попапе теперь показываются до трех знаков после запятой. Список легче читать, особенно в компактном окне.

### Работа в браузере

* **Релиз 1.0.0:** версия расширения обновлена до 1.0.0.
* **Готовые сборки обновлены:** пакеты для Firefox и Chrome-based браузеров пересобраны для этой версии.

---

## Технически

* Добавили хранение ручных курсов отдельно от автоматически загруженных данных. Практический эффект: пользовательские значения можно повторно применить после обновления курсов.
* Добавили проверки для ручных курсов и формата результата конвертера. Это помогает сохранять одинаковое поведение в разных сценариях.

---

## Что это значит для пользователя

Расширение стало гибче для повседневного использования: можно смотреть цены на Kufar.by не только по автоматическому курсу, но и по своему ориентиру. При этом автоматические курсы по-прежнему доступны, а ручное значение можно убрать в любой момент.

---

## Полный список изменений

* Добавили возможность вручную изменить курс USD, EUR или RUB в попапе.
* Добавили сохранение ручных курсов и повторное применение после обновления автоматических курсов.
* Добавили возможность убрать ручной курс и вернуться к автоматическому значению.
* Обновили конвертер: он учитывает ручные курсы и показывает результат в BYN понятнее.
* Сделали отображение курсов короче и удобнее для чтения.

# Easier Exchange Rates

## Summary

This version makes it easier to adjust exchange rates directly in the extension popup. If the automatic rate is not the one you want to use, you can enter a custom rate, and the extension will use it for display and conversion. The release is also prepared as version 1.0.0 for Firefox and Chromium-based browsers.

---

## What changed

### For Kufar.by users

* **Custom rates in the popup:** you can now manually change the USD, EUR, or RUB rate. This is useful if you want to use a bank rate, an exchange-office rate, or another reference instead of the automatic rate.
* **Visible manual values:** manually changed rates are highlighted in the list. This makes it easier to see where a custom rate is used and where the automatic rate is still used.
* **More compact popup:** the extension popup now has a fixed width and uses a dark design. Rates and the converter should look cleaner in a small browser popup window.

### Rates and currencies

* **Rates are saved:** a custom rate is saved in the browser and keeps applying after rates are refreshed. This reduces the risk of a manually chosen value disappearing after new data is loaded.
* **Automatic rate can be restored:** for a changed rate, you can remove the manual value and use the automatically fetched rate again.
* **Converter uses custom rates:** if a currency has a custom rate, the popup converter calculates BYN with that rate. The result is now shown in a clearer format: a BYN amount with two decimal places.
* **Shorter rate display:** rates in the popup are now shown with three decimal places. The list is easier to read, especially in the compact popup.

### Browser experience

* **Version 1.0.0:** the extension version was updated to 1.0.0.
* **Updated browser packages:** packages for Firefox and Chromium-based browsers were rebuilt for this version.

---

## Technical notes

* Custom rates are now stored separately from automatically loaded rate data. Practical effect: user-entered values can be applied again after rates refresh.
* Added checks for custom rates and converter result formatting. This helps keep behavior consistent across different cases.

---

## What this means for users

The extension is now more flexible for everyday use: you can view Kufar.by prices not only with the automatic exchange rate, but also with your own reference rate. Automatic rates are still available, and a custom value can be removed at any time.

---

## Full changelog

* Added the ability to manually change the USD, EUR, or RUB rate in the popup.
* Added saving for custom rates and re-applying them after automatic rates refresh.
* Added the ability to remove a custom rate and return to the automatic value.
* Updated the converter so it uses custom rates and shows the BYN result more clearly.
* Made rate display shorter and easier to read.
* Updated the popup layout and width.
* Updated the extension version and ready browser packages to 1.0.0.
